# Rock Paper Scissors Game

A modern, interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Description

This project is a web-based implementation of the classic hand game "Rock Paper Scissors". It features a vibrant, animated gradient background, 3D emoji assets, sound effects, and a live scoreboard to track the user's wins against the computer.

## Features

- **Interactive Gameplay:** Click on Rock, Paper, or Scissors to play against the computer.
- **Dynamic UI:**
  - Animated background with shifting colors.
  - 3D animated hand gestures for choices.
  - Visual feedback on hover and click.
- **Sound Effects:** Distinct sounds for winning, losing, and drawing.
- **Score Tracking:** Real-time score updates for both the player and the computer.
- **Responsive Design:** Works well on different screen sizes.
- **Reset Option:** A button to reset the scores and start over.

## Technologies Used

- **HTML5:** Structure of the game.
- **CSS3:** Styling, flexbox layout, and keyframe animations for the background and interactions.
- **JavaScript:** Game logic, DOM manipulation, and audio handling.

## How to Play

1. Open `index.html` in your web browser.
2. Choose your weapon: Rock, Paper, or Scissors by clicking on the corresponding icon.
3. The computer will randomly select its move.
4. The winner is decided based on standard rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
5. The result is displayed with a message and sound effect.
6. Scores are updated automatically.
7. Click "Reset Game" to clear scores and restart.
